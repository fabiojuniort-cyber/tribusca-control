# TriBusca — manifesto do Brand Kit v1

Fonte textual copiada e preservada no GitHub: [Manual de Marca v1](BRAND_MANUAL_V1.md). Os ativos binários oficiais permanecem no acervo aprovado `/TriBusca/Branding/v1/` da Biblioteca do usuário (e no bundle `tribusca-brand-kit-v1.zip`). Este manifesto identifica os arquivos; ele não afirma que os binários foram publicados neste repositório. Antes de implementar UI ou site, obtenha os arquivos oficiais; não redesenhe o logo a partir desta descrição.

| Arquivo oficial | Uso |
| --- | --- |
| `tribusca-logo-horizontal-light.png` | Assinatura para fundos claros |
| `tribusca-logo-horizontal-dark.png` | Assinatura para fundos escuros |
| `tribusca-logo-vertical.png` | Composição vertical |
| `tribusca-icon.png` | Favicon, aplicativo, avatar |
| `tribusca-wordmark.png` | Wordmark isolado |
| `tribusca-logo-with-descriptor.png` | Assinatura com descriptor institucional |
| `tribusca-logo-monochrome-dark.png` | Aplicação monocromática |
| `tribusca-brand-guide-board.png` | Visão do conjunto visual |
| `tribusca-brand-kit-v1.zip` | Bundle de ativos aprovados |

A paleta, tipografia, aplicações e usos proibidos constam no manual. Quando a frente frontend/site iniciar, incluir os binários aprovados no repositório de implementação por PR revisado e confirmar integridade/licença; até lá o acervo original continua sendo a fonte dos bytes.
